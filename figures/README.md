# Figures

This directory is intended to store publication-quality figures generated by the R scripts contained in the `scripts/` directory.

## Contents

The scripts reproduce all figures presented in the accompanying manuscript, including:

- Main figures
  - Figure 1–11
- Supplementary figures
  - Supplementary Figure S1

Figures are exported as high-resolution image files (e.g., PNG) suitable for publication. Individual scripts generate the corresponding figure panels, while dedicated patching scripts combine panels into the final composite figures where applicable.

## Reproducibility

All figures can be regenerated by running the scripts in the order described in the repository `README.md`. Output filenames and export settings are specified within each script.

## Note

To minimise repository size, generated figure files are not included by default. Running the analysis scripts will recreate all figures from the input datasets.

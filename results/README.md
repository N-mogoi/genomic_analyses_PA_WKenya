# Results

This directory contains the processed outputs generated by the R scripts in the `scripts/` directory.

## Contents

The scripts generate publication output files, including:

- Summary statistics tables (`.csv`)
- Statistical test results (`.csv`)
- Effect size estimates
- Supplementary tables
- Intermediate processed datasets used for downstream analyses

Representative outputs include:

- Antimicrobial susceptibility summaries
- Multidrug resistance burden statistics
- Quorum-sensing summary statistics
- Fisher's exact test results
- Wilcoxon rank-sum test results
- Supplementary statistical tables accompanying the manuscript

## Reproducibility

Running the scripts in the order described in the repository `README.md` will regenerate these files automatically. Output filenames are defined within each script and correspond to the figures and supplementary tables presented in the manuscript.
